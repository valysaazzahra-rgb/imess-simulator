# iMessage Draft Simulator
Next.js app: atur kontak, pfp, wallpaper, pesan (teks/foto), reply, reaction, status, dan timestamp. Buka preview untuk meninjau percakapan yang dapat discroll, lalu ambil screenshot manual.

    npm install
    npm run dev      # http://localhost:3000

Deploy: push ke GitHub lalu import di vercel.com (tanpa konfigurasi tambahan), atau jalankan `npx vercel`.
